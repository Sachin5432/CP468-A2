# CP468-A2

How To Run The Program:

1. Make sure you have python 3.12+ installed.
2. Create **and activate** a virtual environment (python venv, uv, conda, etc.).
3. Install packages listed in `requirements.txt` (for example: `pip install -r requirements.txt`)
4. To run the simulation, run the `sim_main.py` file.
5. To run the agent training, run the `train_main.py` file.
